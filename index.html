Open this over http(s), not as a local file

This app loads Three.js as an ES module, which browsers block when a page is opened directly from disk (file://). Host it somewhere and open that link instead:

  • Netlify Drop — go to netlify.com/drop on a computer, drag this file in, open the link it gives you on your phone.
  • GitHub Pages — push this file to a repo and enable Pages.
  • Termux (Android) — pkg install python, then python -m http.server in this file's folder, then open http://localhost:8000/ in Chrome.
  • Same Wi-Fi as a PC — run a local server on the PC, open http://<PC's-IP>:8000 on your phone.

Build the physical pyramid
  1. Material. Cut 4 identical trapezoids from a clear CD case, report cover, or overhead-projector transparency.
  2. Proportions. A working ratio: top edge ≈ 1 cm, bottom edge ≈ 6 cm, height ≈ 3.5 cm, sides angled at 45°. Scale it up for tablets, down for phones.
  3. Assemble. Tape the four trapezoids edge-to-edge into a truncated pyramid (frustum), narrow opening at the top.
  4. Place. Set it wide-edge-down, centered on the diamond guide in the middle of the screen.
  5. View. Dim the room, tap "Enter fullscreen showcase," and look at each face from eye level.
